# SONIC youth

Раннер на Python + Pygame. Бегаешь, прыгаеться, музыка переключается,
скримеры, боссы, кооп на двоих. Не всё идеально, но играть норм.

## Как запустить

Скачай репозиторий, поставь зависимости:

    pip install pygame pillow

Запусти `gaame.py`.

## Управление

- **W** — прыжок
- **A** — влево
- **S** — присесть
- **D** — вправо

Кнопки можно поменять в настройках.

## Что внутри

- Кооп на двоих
- Выбор персонажей + загрузка своего
- Кастомные клавиши для каждого игрока
- Скримеры, боссы, NPC
- Рекорд сохраняется
- Погодные эффекты
