# SONIC youth

Раннер на Python + Pygame. Бегаешь, прыгаеться, музыка переключается,
скримеры, боссы, кооп на двоих. Не всё идеально, но играть норм.

## Как запустить

### Вариант 1: Скачать готовую игру

1. Скачай папку `release/` из репозитория
2. Запусти `install.bat` — он создаст ярлык на рабочем столе и сразу запустит игру
3. Или просто запусти `gaame.exe` из папки `release/`

### Вариант 2: Запуск из исходников

1. Установи Python 3.x (если нет) — https://www.python.org/downloads/
2. Открой терминал в папке проекта
3. Установи зависимости:
       pip install pygame pillow
4. Запусти:
       python gaame.py

## Управление

- **W** — прыжок
- **A** — влево
- **S** — присесть
- **D** — вправо

Кнопки можно поменять в настройках.

## Что внутри

- Кооп на двоих
- Выбор персонажей + загрузка своего
- Кастомные клавиши для каждого игрока
- Скримеры, боссы, NPC
- Рекорд сохраняется
- Погодные эффекты
